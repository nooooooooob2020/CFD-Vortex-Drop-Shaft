# CFD Simulation of Vortex Drop Shaft

Replication of the vortex drop shaft experiment by Zhao et al. (2006) using ANSYS Fluent.

## Objective

To investigate the hydraulic behaviour of a vortex drop shaft and compare CFD predictions with experimental observations.

## Methodology

- 3D geometry developed in ANSYS SpaceClaim
- ~596K-cell computational mesh
- Transient VOF multiphase modelling
- Realizable k-ε turbulence model
- Analysis of pressure, velocity, wall shear stress and turbulent dissipation

## Results

- Reproduced characteristic swirling flow and central air core
- Analysed pressure and velocity variation along the shaft
- Compared CFD predictions with published experimental observations

## Software

ANSYS SpaceClaim | ANSYS Meshing | ANSYS Fluent
